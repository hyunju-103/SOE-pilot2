# Changes — 2026-10-27 (start screen, GDP lookup, layout)

Rebuild: `python report.py --demo --allow-download --out SOE-Fiscal-Risk-Final.html`. All 14 checks in `tests/` pass, including `check_snapshot_sync.py`. No model formula, calibration or default value changed.

## 1. Country GDP: filled in automatically, then units; LCU or US$

Expected Fiscal Cost › Settings, and Shock Scenarios › "Show costs as a share of GDP" (one shared GDP).

- **World Bank series** toggle: *Local currency* — GDP (current LCU), `NY.GDP.MKTP.CN` — or *US dollars* — GDP (current US$), `NY.GDP.MKTP.CD`. The default follows the statements' currency (US dollars when the statements are in USD, otherwise local currency).
- **Country and year → GDP is looked up and filled in automatically.** No Apply button. The year starts at the analysis year (EFC year or shock base year). If the data have a `Country` column (ISO3 code or World Bank name), that country is chosen and GDP is filled in without any click.
- **Units** (Billions by default; Millions, Thousands, Full units, As in the statements) only change how the number is shown and typed. The model always stores GDP in the statements' own scale.
- **Currency check:** a GDP in the statements' currency is used at once. A GDP in another currency (for example US$ against FCFA statements) is shown with a dashed border and **not used** until the user ticks "Use it anyway". No FX conversion is guessed.
- **Year check:** if the GDP year differs from the analysis year, a note says so with a one-click "Use {year}".
- Typing a value by hand still works and overrides the lookup.
- **Bug fixed:** the World Bank country-list API returns no currency, so every country (Senegal included) used to show "Currency mismatch" against FCFA statements and Apply stayed disabled. The page now carries its own list of the 217 World Bank economies with the ISO currency of each LCU series; it also works offline.
- Lookups are cached per series, country and year; switching tabs re-syncs the field with the shared GDP.

## 4. New start screen (Home)

Revised the same day after review: an open "What would you like to analyze?" suggested the tool does any analysis, so the screen now says what it is for and what it calculates. From top to bottom:

1. **Headline and scope:** "About this tool..." (first "Analyze the fiscal risk of your state-owned enterprises"), left-aligned on the same edge as the intro and the sections below, a two-line description, and a line saying what is out of scope (budget forecasts, state banks and other financial SOEs) with a link to About.
2. **What the tool calculates:** four steps in order: health ratios, **distress score (Altman Z″-EM)**, expected fiscal cost (PD × EAD × LGD), shocks and warnings. The Altman step explains the score in plain words, shows the three zones (distress ≤ 1.1, grey 1.1–2.6, safe > 2.6) and folds out the formula (6.56 X1 + 3.26 X2 + 6.72 X3 + 1.05 X4 and what each ratio is). Coefficients and cut-offs are read from `config.py`.
3. **Load data:** the drop area from the previous Home (same explanation text), in a light sky-blue dashed panel with the upload bar inside; drop a file anywhere on the panel. Under it, the folds **Required and optional columns** and **Data preview** (and **Column mapping** after an upload), then a compact block: **Now showing**, **Or try built-in data** (Example, Demo portfolio, Long panel) and **Standard template** (Template and Dictionary CSV).
4. **What the tool finds in this data:** four question cards with today's answers, each opening its tab:

| Question | Answer shown | Opens |
|---|---|---|
| Which SOEs are in trouble? | SOEs in distress or grey zone, with a zone bar | Distress Indicator |
| What could they cost the budget? | Portfolio expected fiscal cost (and % of GDP once GDP is set) | Expected Fiscal Cost |
| What if a shock hits? | SOEs that fall a zone under the standard stress; rise in expected cost by year 3 | Shock Scenarios |
| What needs action now? | SOEs with an alert signal (and on watch) | Early Warning |

The rest of the previous Home (data quality, how to use it, scope, toolkit modules, tabs at a glance, glossary, "what the tool is not", analyst notes) is unchanged on **About the tool and your data** (`#view-about`), linked from the start screen. Like Government Support and Technical notes, its tab appears only while it is open. The uploaded government-support card appears on About.
